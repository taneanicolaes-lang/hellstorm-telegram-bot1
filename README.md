# Hellstorm — Telegram-игра «Битва замков»

Hellstorm — это не сайт, а игровая Telegram-интеграция для бота, созданного через @BotFather.

## Возможности

- личная крепость каждого игрока;
- золото, дерево, камень и энергия;
- добыча ресурсов раз в час;
- ежедневная награда;
- случайные атаки на другие замки;
- уровни, опыт, победы и поражения;
- защитный щит нового замка;
- зал славы;
- постоянное хранение прогресса в Supabase;
- webhook-обработчик, совместимый с Netlify Functions.

## Переменные для запуска

- `TELEGRAM_BOT_TOKEN` — токен, который выдаёт @BotFather.
- `TELEGRAM_WEBHOOK_SECRET` — длинная секретная строка для защиты webhook.
- `SUPABASE_URL` — адрес проекта Supabase.
- `SUPABASE_SERVICE_ROLE_KEY` — серверный ключ Supabase.

После публикации webhook должен указывать на `/telegram` или `/.netlify/functions/telegram`.

## Важно

Этот репозиторий содержит оригинальную игровую логику Hellstorm и не копирует исходный проект Castlebot. Для подключения Telegram нужен токен своего бота из @BotFather.
